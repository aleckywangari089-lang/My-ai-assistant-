A simple AI chatbot using FastAPI + OpenAI.

## Run locally
1. Install dependencies: `pip install -r requirements.txt`
2. Create a file named `.env` with: `OPENAI_API_KEY=sk-your-key-here`
3. Start: `uvicorn app:app --reload`
4. Open http://127.0.0.1:8000
